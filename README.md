# Муравьиный алгоритм для задачи коммивояжёра

Курсовая работа по дисциплине «Алгоритмы и структуры данных»: исследование и реализация муравьиного алгоритма (ACO) для TSP с веб-интерфейсом на Flask.

## Запуск

Нужен Python 3.10 или новее. Команды для Windows (PowerShell), из корня проекта:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Откройте http://127.0.0.1:5000. На Linux/macOS вместо второй строки: `source venv/bin/activate`.

> Сейчас вместо настоящего алгоритма работает **заглушка** `MockACO` (маршруты случайные): она нужна, чтобы интерфейс можно было делать, не дожидаясь ядра.

## Тесты

```powershell
pytest -q
```

## Структура

```
core/          алгоритмы
web/           Flask-сервер и страница
  app.py         create_app(), эндпоинты
  validation.py  проверка входных данных, случайные города
  mock_aco.py    заглушка движка с тем же интерфейсом, что у ACO
  templates/     index.html
  static/        render.js (рисование), app.js (логика страницы), styles.css
experiments/   эксперименты и графики
data/          тестовые задачи (JSON, CSV)
tests/         pytest
API.md         контракт между core и web
```

Формат запросов и ответов - в [API.md](API.md).

## Работа со страницей

- **Города:** клик по холсту добавляет город, правая кнопка по городу удаляет; «Случайные города» (поля `n` и `seed`); текстовое поле (`x, y` по строке); загрузка файла - JSON (`{"cities": [[x, y], …]}`) или CSV с колонками `x`, `y` (примеры в `data/`).
- **Параметры:** подсказки рядом с каждым полем. Новые параметры применяются после «Сброс».
- **Кнопки:** «Шаг» - одна итерация, «Запуск» - шаги подряд до заданного числа итераций, «Пауза», «Сброс».

## Если что-то не так

- **«Сессия устарела»** - сервер перезапустился (в режиме `debug=True` он перезапускается при каждом сохранении файла), состояние на сервере потеряно. Нажмите «Шаг»: задача создастся заново.
- **Браузер показывает старый `app.js`** - обновите страницу через Ctrl+F5.
