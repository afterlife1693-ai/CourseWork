# Муравьиный алгоритм для задачи коммивояжёра

Курсовая работа по дисциплине «Алгоритмы и структуры данных»: исследование и реализация муравьиного алгоритма (ACO) для задачи коммивояжёра с веб-интерфейсом на Flask.

## Как запустить

Нужен Python 3.10 или новее. Команды для Windows (PowerShell), запускать из корня проекта:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

После этого откройте http://127.0.0.1:5000. На Linux и macOS вместо второй команды используйте `source venv/bin/activate`.

> Класса `ACO` в `core/` пока нет, поэтому алгоритм работает через переходник `web/core_engine.py`. Маршруты в нём строит `core.aco.construct_tour`, задачу и длины маршрутов даёт `TSPInstance`, а феромон обновляет сам переходник. Когда `ACO` появится, переходник можно удалить (подробности в [API.md](API.md)).

## Структура проекта

```
core/          алгоритмы
web/           Flask-сервер и страница
  app.py         create_app() и эндпоинты
  validation.py  проверка входных данных
  core_engine.py переходник к core: Ant System на функциях ядра, пока нет ACO
  mock_aco.py    старая заглушка, больше не используется (файл можно удалить)
  templates/     index.html
  static/        render.js (рисование), app.js (логика страницы), styles.css
experiments/   эксперименты и графики
data/          тестовые задачи (JSON и CSV)
tests/         тесты pytest
API.md         описание обмена данными между core и web
```

Форматы запросов и ответов описаны в [API.md](API.md).

## Как пользоваться страницей

- **Города.** Клик по холсту добавляет город, правая кнопка мыши по городу удаляет его. Можно сгенерировать случайные города (поля `n` и `seed`), ввести их текстом (по одному `x, y` на строку) или загрузить файл: JSON вида `{"cities": [[x, y], …]}` либо CSV с колонками `x` и `y`. Примеры файлов лежат в `data/`.
- **Параметры.** Рядом с каждым полем есть короткое пояснение. Новые значения применяются после «Сброс».
- **Кнопки.** «Шаг» выполняет одну итерацию, «Запуск» выполняет итерации подряд до заданного числа, «Пауза» останавливает запуск, «Сброс» начинает всё заново.

## Если что-то пошло не так

- **Страница пишет, что сессия устарела.** Значит, сервер перезапустился (в режиме `debug=True` он перезапускается при каждом сохранении файла), и его состояние потеряно. Нажмите «Шаг», задача создастся заново.
- **Браузер показывает старый `app.js`.** Обновите страницу сочетанием Ctrl+F5.
